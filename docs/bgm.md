# Menu background music

`assets/audio/bgm/stahlmarsch_zum_sieg.mp3` is the supplied 60.160-second MP3. It plays once across title, skill selection and stage selection without restarting between those screens. Other screens and hidden/blurred pages pause it. Returning to an eligible screen resumes its position; once ended, it stays ended until the next result screen or page reload.

Browser autoplay restrictions require the first trusted pointer/key interaction before audible playback. No additional start button is added. One streaming HTMLAudioElement and, when available, a gain on the existing AudioContext keep full-song decoded buffers out of the SE cache. BGM gain is 0.23 and SE gains are unchanged. Playback errors cannot block the game or create automatic retry loops. The main render loop only checks playback state; it does not restart a playing track.

Opening a new mission result screen resets the theme to the beginning and waits for active result/success/failure SE voices to finish. Voice removal on the actual Web Audio `onended` event releases the wait, rather than a fixed timer. If the result SE is unavailable and no voice plays, BGM can start immediately. Both success and failure results play the theme once; opening/closing the achievement overlay does not restart it. The same streaming element is reused, and a pending play request is paused if the result SE is still playing.
