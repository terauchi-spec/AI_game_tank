# 脱出（テスト）

開発者モードのステージ選択に追加。正式10ステージの解放順には含めず、戦績・称号・ランキング・スキル解放は保存しない。

- 密林5エリアが連続する（各2,400px）。既存の密林素材・輪郭配置・描画キャッシュ・敵AIを再利用。
- 最終エリアのEXITに徒歩で入り、連続5秒待機すると作戦成功。円から出る、乗車する場合は待機時間をリセット。半径90pxと円の描画は潜入と共通。
- 各エリアで川と荒野の湖をそれぞれ1回抽選。両方出現する場合もある。
- 川：75%、幅35〜600px、橋1本（幅64〜256px）。流速・流向・サイズの抽選は既存ステージと同じ関数。
- 湖：55%、基準サイズの20〜150%。基準幅600〜820px、基準高さ440〜680px（エリア高の42%上限）。既存の楕円判定・描画を利用。
- 水面・橋の周囲は遮蔽物を除去し、開始地点とEXITは安全な場所を確保。水中の徒歩移動は既存の泳ぎを利用。
- 各エリアに既存の配置処理で敵兵8人・敵戦車2両を配置。開始地点には通常の戦車1両。無敵や弾薬無制限は強制しない。
- 境界をまたぐ草むらは隣の密林チャンクにも描画。遮蔽物の輪郭は内部境界を越えないように配置する。

検証：新規テストで選択制限、連続5エリア、開始/EXITの安全、水域サイズと抽選閾値、待機中断/乗車/成功、保存除外、通常ステージへの復帰を確認。密林・潜入の脱出/描画・決戦・ステージ選択/準備・開発者制御・戦闘の回帰テストを実施。iPhone実機・Cloudflareのデプロイは別途確認が必要。
