# 脱出（テスト）

開発者モードのステージ選択に追加。正式10ステージの解放順には含めず、戦績・称号・ランキング・スキル解放は保存しない。

- 密林5エリアが連続する（各2,400px）。既存の密林素材・輪郭配置・描画キャッシュ・敵AIを再利用。
- 最終エリアのEXITに徒歩で入り、連続5秒待機すると作戦成功。円から出る、乗車する場合は待機時間をリセット。半径90pxと円の描画は潜入と共通。
- 各エリアで川と荒野の湖をそれぞれ1回抽選。両方出現する場合もあるが、岸の描画を含め重ねない。
- 川：75%、幅35〜600px。密林だけサイズ抽選を細幅寄りに変更（35+乱数^2.5×565）。160px以下は橋なし、それ以外は橋1本（幅64〜256px）。流速・流向と他エリアの抽選は維持。
- 建物：コンクリートの見張り台は出現させない。木の小屋2種・コンクリートの建物・木の見張り台から、1エリア0〜2棟、5エリア全体で最大5棟。生成前に割り当て、水域の除去後も増やさない。
- 湖：55%、基準サイズの20〜150%。基準幅600〜820px、基準高さ440〜680px（エリア高の42%上限）。既存の楕円判定・描画を利用。
- 川と湖の水面の間は80px以上離す（両方の岸キャッシュ各36pxも重ならない）。湖のサイズ・抽選率を変えずに位置を調整し、大きい湖で必要な場合だけ川と橋も一緒に移動する。開始地点・EXITの余白も確保する。
- 湿地と同じ沼を密林ステージ全体で0〜5個配置。大きさ（幅105〜260px、高さ48〜106px）、徒歩30%・地上車両60%の速度、潜伏不可の挙動とキャッシュ描画を再利用。川・湖・橋・遮蔽物・開始地点・EXITを避け、生成時のみ最大400回の配置試行を行う。
- 水面・橋の周囲は遮蔽物を除去し、開始地点とEXITは安全な場所を確保。水中の徒歩移動は既存の泳ぎを利用。
- 各エリアに既存の配置処理で敵兵8人・敵戦車2両を配置。開始地点には通常の戦車1両。無敵や弾薬無制限は強制しない。
- 境界をまたぐ草むらは隣の密林チャンクにも描画。遮蔽物の輪郭は内部境界を越えないように配置する。
