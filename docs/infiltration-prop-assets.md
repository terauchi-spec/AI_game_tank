# Infiltration prop assets

Generated with the built-in image_gen tool (transparent_background: true). Used only by the infiltration stage.

PNG sources were cropped to the object's alpha bounds and downsampled to at most 256×256, then encoded as WebP quality 80, method 6; transparency is preserved. Original collision rectangles, navigation and object counts remain unchanged.
