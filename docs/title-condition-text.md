# 称号の取得条件・説明の整合性

- 複合実績4種は、必要な2軸の名前と各Lv5の条件を明記する。
- 機動・戦術・連携の説明はLv判定を含めた実際の必要量に合わせる。距離・連携ポイントは評価点の四捨五入があるため目安として表示する。
- 連携は救助3pt、同乗中の共同撃破1pt、相棒が参加した資料4pt。共同制圧4秒または双方が参加した資料1件につきそれぞれ1pt・2ptを追加し、この時間由来の加点は合計8ptまで。
- 「影の相棒」は相棒単独の資料回収も対象。「マルチキルの達人」の4秒は撃破間隔を指す。
- 旧表記は「実績」に統一。全戦域の覇者は公開中の9ステージが対象。
- リリース予定のない決戦では、新たな称号授与・取得回数加算・称号による階級昇格を行わない。既存の獲得履歴は維持する。
- 決戦の除外以外は取得判定・難易度を変更しない。毎フレームの処理や描画は追加しない。
