# 称号の取得条件・説明の整合性

- 複合実績4種は、必要な2軸の名前と各Lv5の条件を明記する。
- 機動・戦術・連携の説明はLv判定を含めた実際の必要量に合わせる。距離・連携ポイントは評価点の四捨五入があるため目安として表示する。
- 連携は相棒の救助3pt、同乗中の共同撃破1pt、相棒が参加した資料4pt。共同制圧4秒につき1pt、双方が参加した資料1件につき2ptを追加し、この2項目は合計8ptまで。味方と1秒以上制圧に参加して完了した拠点は1か所8ptで、最大24pt。
- 「最前線の指揮官」は全拠点の制圧に参加し、うち2か所以上を共同で制圧。防衛撃破5体以上と任務遂行・連携Lv5も必要。
- 救出の評価は任務達成率、要人のライフ、未発見で護衛した距離を記録する。「ゴースト」はプレイヤーと要人が無発見で、要人が無傷のまま救出を完遂することが条件。「不屈の生還者」は要人も無傷での完遂が必要。
- 「影の相棒」は相棒単独の資料回収も対象。「マルチキルの達人」の4秒は撃破間隔を指す。
- 「全戦域の覇者」は破壊・潜入・制圧・救出の各難度、公開中の12ステージが対象。
- 開発中の決戦では指揮施設の端末への命中、脱出、移動要塞の損傷を評価に反映する。新規の称号授与と回数加算は公開ステージが対象。既存の獲得履歴は維持する。
