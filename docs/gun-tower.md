# 機関銃塔

- 新しい `tower` 種別の1人用固定乗り物。燃料0・速度0・機銃弾500発・主砲なし。ガソリン取得・河川流・爆風移動・車両の慣性移動を適用しない。
- 破壊（上級）と制圧（上級）だけに各3基を配置する。中級コピー・初級・潜入・決戦・訓練・エリアデバッグには出現しない。起動時の有限探索で遮蔽物・水・車両を避ける。
- 初期射手は銃塔ごとに独立して50%で青兵。銃塔が空けば近くの通常青兵も搭乗可能。射手はその場に固定され、通常の巡回・武器AIを実行しない。
- 敵射手への銃撃・爆風・気絶で空席となり、10秒間は別の青兵が乗り直さない。銃塔の残弾を保持してプレイヤーまたは相棒が奪取できる。
- ガトリングは射撃間隔0.065秒、弾速1000px/秒、射程600px（60m、敵の通常単発銃150pxの4倍）。1射1発を消費し、残弾0で停止。敵・プレイヤー・相棒で共通の弾倉を使用する。
- 直前位置から現在位置までの線分で、地形・人物の最初の衝突を解決する。敵弾も発射した射手以外の敵兵に当たる。味方射撃の得点は既存のプレイヤー／支援区分に従う。
- 遮蔽物は8発命中ごとに半径10pxの小範囲を削る。制圧アンテナ等の破壊不可の構造物は保護し、貨物は既存の専用ダメージ処理を使う。
- プレイヤーはAで搭乗・降車、D/BまたはS長押しで射撃。スマホはB/Sのドラッグで照準。燃料ゲージは空、弾薬は残弾/500を表示する。
- 相棒は指示ルート上50px以内の空いた銃塔に搭乗し、ルート移動を終了して固定射撃する。短押しの呼び戻しで降車し、離れた場合の合流でも銃塔を移動させない。プレイヤーとの同乗は不可。
- 銃塔の図形は既存Canvasと人物WebPで描画し、新たな画像読み込みを行わない。索敵は0.15秒間隔、空席の敵兵確認は0.5秒間隔。弾の遮蔽物候補は既存空間グリッドで絞る。
