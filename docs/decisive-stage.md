# 13 決戦（開発者モード）

1. 草原から出撃し、砂漠街5エリアを突破する。
2. 最後の砂漠街で最高指揮通信施設の正面入口に徒歩で近づき、Aで入る。外観は透過WebPを使用。PNGの元素材は `docs/decisive-art/` に保存する。
3. 潜入（初級）と共通の間取り・家具・衛兵AIを使う地上階、地下1階、地下2階を進む。地下2階のコンピューターを設置爆弾で破壊し、地上階の施設外にあるEXITで5秒待つ。
4. 砂漠エリアから味方部隊との進軍を開始する。3つの砂漠エリアを抜け、移動要塞を破壊すると作戦成功になる。

施設潜入中は地上マップの状態を保持する。作戦IDと記録は全区間で `decisive`。コンピューター破壊で任務達成率25％、脱出で50％となり、残りの50％は移動要塞の破壊進捗に対応する。

回帰テストは `node --test tests/*.test.cjs`。決戦の通しテストは `node --test tests/decisive.test.cjs`。
