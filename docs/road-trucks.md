# 破壊ステージの敵道路トラック

破壊（中級・上級）の通常出撃のみが対象。生成された道路1本につき必ず1台の青い軍用トラックが進入する。道路自体の生成確率は変更しない。初級・潜入・制圧・決戦・訓練・エリアデバッグでは発生しない。

道路が画面に入ると、左または右から各50%で進入。出撃ごとに道路単位で、すぐ進入する場合と、画面に映っている間に2〜5秒待って進入する場合を各50%で選ぶ。画面から離れると待機時間の消化も止まる。片道190px/秒で走行する。複数車線では進行方向に応じた車線を使い、単車線では中央を使う。

- 50%：画面内の道路途中で停車し、荷台付近から通常の青兵1〜3人を0.4秒間隔で降ろす。兵士は既存の通常巡回AIへ合流する。全員が降りたら発進し、反対側へ走り去る。
- 50%：停車も降車も行わず、反対側へ走り去る。

兵士は道路上の衝突のない位置にだけ生成する。荷台付近が兵士・戦車・車両・プレイヤー等で塞がれている間は待機し、空いたら再試行する。遠方への安全地点検索は行わない。終了した道路イベントは同じ出撃中に再発生しない。新しい出撃では状態を初期化。一時停止中は進まない。

既存のトラック描画へ青い配色を追加し、新規画像は読み込まない。イベント数は道路数に限定し、降車時のみ範囲を限定した安全確認を行う。道路の待機・完了イベントは毎フレームの経路探索を行わず、描画は画面内に限定する。

検証：左右進入・50%境界・1〜3人降車・巡回初期状態・障害物待機と再試行・再出現防止・対象ステージ・一時停止・再初期化を自動テスト。通常の中級・上級マップ生成と、スマホ幅・PC幅のブラウザ表示も確認。

## 破壊可能化（2026-11-05）

青トラックの耐久力は5。通常銃・機銃・ガトリングは1発1、狙撃は1発2、主砲直撃は5のダメージ。敵トラックが設置爆弾を踏むと起爆する。走行前後の車体を判定するため、フレーム間で爆弾を通り過ぎても起爆する。砲撃・航空爆弾・オブジェクト等の爆発も、爆風が車体に届けば破壊する。破壊後は走行・降車を停止し、既存の車両残骸描画で残骸を残す。すでに降りた兵士は通常の敵兵として行動し続ける。荷台内の未降車兵は出現しない。

弾は車体への線分判定を使い、銃撃のすり抜けを防ぐ。車体より手前の遮蔽物を優先し、ガトリングは既存の着弾順序判定、狙撃は既存の貫通処理へ接続する。画面に未出現・退出済み・破壊済みのトラックは被弾しない。新規画像や経路探索は追加しない。
