# 味方の接触救助

- 味方兵（増援スキルを含む）、相棒、猟犬を接触救助した瞬間、頭上に白縁の赤十字を1つ表示する。約0.8秒で約26px上昇しながら消える。
- 接触救助後は15秒間再気絶しない。相棒のHP0からの救助にも適用する。
- 時間経過で自然復帰した味方兵・相棒の再気絶防止は従来の5秒間。猟犬の自然復帰時の挙動は維持する。
- 増援は制圧以外でも徒歩・非潜伏・視線が通る距離22px未満の接触で救助可能。猟犬の接触範囲は従来どおり。
- 保護時間はゲーム更新のdtで減らし、停止中は進めない。HPダメージ・死亡判定・敵兵の気絶処理は従来どおり。
- 赤十字は既存の上限付きパーティクル配列・画面外カリング・更新処理を共用する。画像読み込みや独立タイマーは増やさない。

検証: `node --test tests/ally-rescue.test.cjs tests/frontline.test.cjs tests/infiltration-partner.test.cjs tests/enemy-bomber.test.cjs tests/tank-combat-bridge.test.cjs`。3スキルすべてで救助直後・14.9秒・15秒超過後を確認し、自然復帰の既存設定も確認する。スマートフォン実機での操作は未確認。
