# 潜入（中級）・先進科学研究所 追加テスト

開発者モードのステージ選択に `TEST 潜入（中級）／先進科学研究所` を追加。
通常の7ステージの解放順は維持し、このテストのスコア・称号・戦績・解放・ランキングは保存しない。

## 構造とルール（2026-10-31更新）

中級専用の間取りは5×7区画の外周を一周できる廊下と、内側の6室で構成。各室を廊下に接続し、室間の扉も生成する。1階の玄関ホールは南側の外周廊下内に収める。2階も同じ外周構造で、階段の位置は両階で共有する。横幅のみ上級由来の従来寸法の95%（900→855）、奥行きは2205を維持。
敵AI・軍用犬・警報・増援、重要資料3か所（各8秒）、脱出5秒は上級の既存処理を共有する。初級・上級の間取り・寸法・素材は変更しない。

床は目地のない薄汚れた白系の樹脂床。512pxの低コントラストな汚れパターンを初回だけ生成・再利用し、区画ごとの線や色分けは描かない。旧タイル床のPNG/WebPは原本として残すが、ゲームでは読み込まない。
館内の照明マスク濃度は従来の35%から68%に変更し、スポットライトと陰の差を強める。敵の視認判定に使う照明計算は変更しない。
1階の屋外は既存の草原テクスチャを再利用。2階の屋外は暗い非歩行領域のまま。

## 素材と寸法（俯瞰スプライトへ再制作）

`assets/indoor/laboratory/` に透過PNG原本とWebPを格納。内蔵ImageGenで家具6点と専用オブジェクト2点を制作した。
ほぼ真上から上面が主体になる視点、南向きの正面、手描き調の細密な質感、暗い輪郭線、低彩度の灰色・くすんだ緑・鈍い茶色・錆色、汚れ・継ぎ目・風化を採用。地面・外部の影・文字は画像に含めない。

| アセット | 用途 |
| --- | --- |
| `lab-bench` | 実験台・小型加熱器・試験管 |
| `lab-storage` | 上面中心の低い薬品保管棚 |
| `lab-analyzer` | 小型分析機器・サンプルトレー |
| `lab-reactor` | フィルター・配管のある純水装置 |
| `lab-medical` | 緑の検査用ベッド |
| `lab-samples` | 携帯用の小型試薬ケース |
| `lab-waste-tank` | 専用オブジェクト：廃液回収タンク |
| `lab-cooling-unit` | 専用オブジェクト：冷却水循環ユニット |

固定寸法は `LABORATORY_PROP_SIZES` に記載。既存の潜入ステージの作戦机（長辺144）、ロッカー（長辺106）、検査ベッドに相当するベッド（長辺104）、木箱等の貨物を参照し、遮蔽物として使える寸法へ調整した。

| --- | --- |
| 実験台 | 112×35.44 |
| 保管棚 | 96×36.38 |
| 分析機器 | 84×57.75 |
| 純水装置 | 112×62.56 |
| 検査ベッド | 34.53×104 |
| 試薬ケース | 56×31.5 |
| 廃液回収タンク | 45.77×54 |

画像本来の縦横比・南向き・種類ごとの固定寸法を維持し、描画と当たり判定を一致させる。試薬ケースを旧大型砲弾パレットの寸法に戻すことはしない。

### 部屋の役割と配置

`laboratoryFurnishFloor` が生成時に一度だけ部屋別の配置を決める。通常の潜入ステージの軍用家具・貨物配置は中級ではスキップし、廊下のランダムな物品を室内の設備へ置き換えた。

| 部屋 | 配置の組み合わせ |
| --- | --- |
| 中央実験室 | 中央の実験台、追加の実験台、分析機器、保管棚、試薬ケース |
| 実験室 | 実験台、分析機器、補助棚、作業台近くの廃液タンク・試薬ケース |
| 機器分析室 | 分析機器、補助実験台、保管棚、冷却装置・試薬ケース |
| 試薬保管室 | 壁沿いの複数の保管棚、試薬ケース |
| 純水・冷却設備室 | 純水装置、制御機器、補助棚、近くの冷却装置・廃液タンク |
| 検査室 | 壁沿いを優先した検査ベッド、検査機器、補助棚 |

部屋の大きさと通行可能な余白に合わせて補助設備を追加し、扉や階段を塞ぐ場合は補助設備を省略する。主設備は各部屋に必ず配置。中央実験室の待機兵は人数とAIを維持し、拡大した実験台の南北2列へ配置する。

家具・貨物は壁、出入口、他の設備と重ならない位置だけに置く。実際の設備矩形を含む移動検査で、部屋の入口同士・部屋内の歩ける領域をつなぐ。外周廊下は通行中心とし、試薬は保管室へ、冷却・廃液設備は用途に合う部屋へ集約。画像・配置探索は毎フレーム追加しない。
通常の銃撃・破壊・炎上・連鎖爆発の処理を共有し、初級・上級の貨物・家具は変更しない。

自動ドアは研究所専用画像を使用せず、他の潜入ステージと同じ縦・横のWebP、開閉時の切り抜き、描画寸法をそのまま使用する。旧 `lab-door` は原本として残すがゲームでは読み込まない。

PNGは長辺768px以内、ゲーム用WebPは長辺256px・品質82。透過余白を除いて縮小し、縦横比を保持する。PNGはCloudflareの静的配信から除外。床・家具・壁と照明は既存キャッシュを再利用し、画像は初回ロードで共有する。
画像生成指示・ピクセル寸法・世界寸法・バイト数は `laboratory-art-prompts.json` に記録。
