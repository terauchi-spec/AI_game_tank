# 密林テストエリア

タイトルの作者名を3回タップして開発者モードを有効化し、スキル選択後の「エリアデバッグ」から「密林」を選択します。

- 密林のみの全長2,400pxのテストエリア。背景は湿地と同じ `terrain/wetland.webp`。
- 添付6点（ヤシ、倒木、小型・大型木造小屋、コンクリート小屋、屋根なし監視塔）を使用。
- 受領形式はJPEG。受領JPEGおよび無加工のPNG保存版を `assets/jungle/` に保持。
- 配置用WebPは外周とつながる白背景を透過し、余白を切り詰め、最大512pxで保存。約373KB（365KiB）。元画像の再生成はしていません。
- 元画像はCloudflare配信対象から除外。WebPは密林選択時だけ読み込み。
- 既存の遮蔽物物理、破壊片、空間グリッド、画面外描画省略を利用。
- 中央の縦通路、左右の小屋・植生・岩、開始地点の全種戦車、無敵・弾数燃料無制限、敵歩兵・戦車を配置。
- 正式ステージのランダム候補には追加していません。

検証：`node --test tests/jungle.test.cjs` で単一エリア構成、全6素材、中央通路、出現地点、当たり判定、描画呼び出し、遅延読み込み、WebP容量および原本保持を確認。
iPhone実機の表示・操作・発熱は未確認。
