# 密林テストエリア

タイトルの作者名を3回タップして開発者モードを有効化し、スキル選択後の「エリアデバッグ」から「密林」を選択します。

- 密林のみの全長2,400pxのテストエリア。背景は湿地と同じ `terrain/wetland.webp`。
- 添付6点（ヤシ、倒木、小型・大型木造小屋、コンクリート小屋、屋根なし監視塔）を使用。
- 受領形式はJPEG。受領JPEGおよび無加工のPNG保存版を `assets/jungle/` に保持。
- 配置用WebPは縁の白・灰色残りと監視塔の支柱間などの閉じた隙間を含めて透過を修正。最大512px、6点合計325,044bytes。受領JPEGと元PNGは変更せず保持し、透過修正版のみゲームに使用。
- 元画像はCloudflare配信対象から除外。WebPは密林選択時だけ読み込み。
- 既存の遮蔽物物理、破壊片、空間グリッド、画面外描画省略を利用。
- 中央の縦通路、左右の小屋・植生・岩、開始地点の全種戦車、無敵・弾数燃料無制限、敵歩兵・戦車を配置。
- 正式ステージのランダム候補には追加していません。
- 破壊片にも密林素材の識別子を保持し、無傷の部分は同じ画像から切り出して描画。既存建物への置換や、透明部分への瓦礫色の四角い描画を抑止。
- 移動・被弾・視線の判定はWebPのアルファから事前生成した32×32セルの輪郭を共用。透明な角と監視塔の隙間を除外し、破壊片では元の輪郭を各破片の範囲で切り取る（判定の粒度は配置サイズの約1/32）。
- 判定データは `python tests/helpers/build-jungle-hit-masks.py` で再生成。実行中の画像読み取りは不要。画像はバージョン付きURLで更新し、既存の遅延読み込み・破片キャッシュ・空間グリッドを維持。

iPhone実機の表示・操作・発熱は未確認。

追加素材：シダとつるが絡む巨木（fern_tree）2本。広葉樹の2倍（332×332px）で中央通路の左右に配置。受領JPEG・背景透過PNG原本を保持。ゲーム用WebPは最大320px。既存の輪郭判定・部分破壊・遅延読み込みを共用。背景透過は画像編集ツールで「白背景と枝葉の隙間を透過し、木の形・葉・シダ・色・構図を維持」と指定。

## 密林の草（2026-11-08）

添付の丸葉草・赤い花の草を合計最大3株配置（2種を交互に使用）。荒野の `spinifexPlacementSize` を共用し約59〜130px四方。中央通路と開始地点を避け、既存の遮蔽物・オブジェクト・草むらと重ならない場所を最大80回試行する。

`spinifex` として既存の徒歩隠密・前景描画・火炎燃焼・爆風による飛散（最大6件）を共用する。硬い遮蔽物にはせず、草むらと同じ矩形の隠密判定を使用。

受領JPEG、無加工PNG保存版（`*_source.png`）、背景透過PNGをGitに保持。背景透過は画像編集で白背景と葉の隙間のみを削除し、形・色・構図を維持するよう指定。ゲーム用は最大256pxのWebPで、密林選択時のみ読み込む。通常ステージの読込数は増やさない。
