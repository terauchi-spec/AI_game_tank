## 決戦の表示制限（2026-10-31）

ステージ10「決戦」の番号・内容・保存ID・クリア記録は維持するが、選択カードは開発者モード時のみ表示する。通常モードでは既存セーブで解放済み／クリア済みでも非表示・選択不可・出撃不可。開発者モードでは従来の進捗または全ステージ表示に従って選択可能。09の通常クリア時に、非公開の10をアンロック通知へ出さない。開発者モードを解除するとカードと残っていた選択を通常状態へ戻す。
